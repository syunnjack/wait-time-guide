# wait-time-guide

Wait Time Guideは、役所・病院・店舗・駅施設などの待ち時間を見て、近くで過ごせる場所へ案内するプロトタイプです。

## Concept

- 施設の現在待ち時間、受付状況、呼び出し目安を比較する
- 待ち時間に合わせてカフェ、喫煙所、漫画喫茶、買い物、食事を提案する
- QRコードや整理券番号から、自分の順番を見失わない導線を想定する
- 将来的に猫の目コム風の混雑表示、民間施設の案内、広告導線へ拡張する
